# CLAUDE.md

Контекст проекта для Claude Code. Читается в начале каждой сессии.

## Что это за проект

`mdview` — минималистичный десктопный просмотрщик Markdown. Не редактор.
Одна кнопка переключает отрендеренный вид и исходный текст.

Цель — **полноценное настольное приложение**, а не демка: пользователь
запускает `.exe` из меню «Пуск» и получает пустое окно, либо делает
двойной клик по `.md` файлу и тот открывается в mdview.

Приоритет платформ: **Windows → Linux → macOS**. Android вне области.

Второстепенная, но реальная цель: код служит учебным материалом по Rust
для владельца проекта (фон — C#). Из этого следуют требования к стилю ниже.

## Стек и версии

| Крейт | Версия | Зачем |
|---|---|---|
| `eframe` / `egui` | 0.36 | окно + immediate mode GUI |
| `egui_commonmark` | 0.25 | рендер Markdown в виджеты egui |
| `egui_extras` | 0.36 | загрузчики картинок (`image`, `file`) |
| `rfd` | 0.17 | нативный диалог открытия файла |

**Эти версии подобраны как совместимый набор.** `egui_commonmark 0.25`
жёстко требует `egui ^0.36`. Поднимать версию egui можно только вместе
с `egui_commonmark`, иначе в дереве окажутся две несовместимые копии egui
и сборка развалится с невнятными ошибками про типы. Проверка: `cargo tree -d`
не должен показывать дубликатов `egui`.

MSRV: 1.95. Edition 2021.

## Архитектура

```
src/main.rs      точка входа, разбор argv, конфигурация окна
src/app.rs       состояние приложения + вся отрисовка
src/document.rs  файл на диске: чтение, слежение, пути картинок
```

### Инварианты, которые нельзя нарушать

1. **`document.rs` не знает про egui.** Никаких `use eframe`/`use egui` в
   этом модуле. Он должен оставаться тестируемым без GUI и переносимым,
   если когда-нибудь UI сменится. Все новые модули работы с данными —
   по тому же принципу.
2. **Всё состояние живёт в структуре приложения.** egui — immediate mode:
   виджетов-объектов не существует, `update()` каждый кадр заново описывает
   экран. Никаких глобальных `static mut`, `lazy_static`, `Rc<RefCell<..>>`
   для состояния UI.
3. **Никакого async-рантайма в основном коде.** `tokio`/`async-std` могут
   приехать транзитивно (через `rfd`), но своего асинхронного кода не пишем.
   Долгие операции — либо синхронно, либо отдельным потоком с каналом.
4. **`unwrap()` / `expect()` на операциях ввода-вывода запрещены.** Ошибка
   чтения файла должна доезжать до пользователя строкой в UI, а не паникой.
   В тестах и на заведомо валидных константах — можно.
5. **Платформенный код — за `#[cfg(windows)]` / `#[cfg(unix)]`.** Сборка под
   каждую из трёх платформ должна проходить всегда, даже если фича там ничего
   не делает.

## Стиль

- **Комментарии и строки интерфейса — на русском.** Идентификаторы, имена
  функций и типов — на английском.
- Комментарии объясняют **почему**, а не что. `// увеличиваем счётчик` —
  мусор. `// canonicalize заодно проверяет существование файла` — по делу.
- В местах, где решение продиктовано системой владения или устройством
  immediate mode GUI, оставлять короткое пояснение: код читает человек,
  изучающий язык. Не превращать это в учебник — 1–3 строки максимум.
- `rustfmt` с настройками по умолчанию, без кастомного `rustfmt.toml`.

## Команды проверки

Перед тем как считать задачу сделанной, прогнать всё:

```bash
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo build --release
cargo tree -d          # не должно быть дубликатов egui
```

Под Windows дополнительно проверить, что release-сборка **не открывает
консольное окно** (за это отвечает `windows_subsystem = "windows"` в main.rs).

## Definition of Done для любой задачи

- Все команды выше проходят чисто.
- Изменение проверено запуском приложения, а не только компиляцией.
- Новая логика работы с данными покрыта юнит-тестом, если её можно
  протестировать без GUI.
- README обновлён, если поменялось поведение, сборка или горячие клавиши.
- ROADMAP.md обновлён: сделанный пункт отмечен, всплывшие проблемы записаны.

## Чего не делать

- Не переписывать на Tauri / Iced / Slint. Выбор egui сделан осознанно,
  обоснование в README.
- Не превращать в редактор. Никакого сохранения `.md`, никакого редактирования
  текста. Просмотрщик.
- Не добавлять телеметрию, автообновление, сетевые запросы. Единственное
  исключение — загрузка картинок по http(s) из самого markdown, и то её
  стоит сделать отключаемой.
- Не добавлять зависимости без явной необходимости. Каждая новая строка
  в `Cargo.toml` — это минуты сборки и мегабайты бинарника. Если сомневаетесь,
  спросите, а не ставьте.
