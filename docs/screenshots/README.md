# Скриншоты для README

Файлы кладутся сюда под именами из таблицы. README ссылается на них
по этим именам, так что переименовывать нельзя — сломаются ссылки.

| Имя файла | Что на снимке |
|---|---|
| `rendered.png` | Главное окно с отрендеренным документом. Лучше всего `samples/demo.md`: там кириллица во всех начертаниях, блок кода с подсветкой, таблица и картинка. |
| `source.png` | Тот же документ в режиме «Исходник» — виден моноширинный шрифт и нумерация строк. |
| `outline.png` | Раскрытая боковая панель с оглавлением, желательно на документе с вложенными заголовками. |
| `search.png` | Открытый поиск с подсвеченными совпадениями. |

## Как снимать

- Окно в обычном размере, не развёрнутое на весь экран: на 4K-мониторе
  развёрнутое окно превращается в нечитаемую марку.
- Светлая тема — README чаще читают на светлом фоне, и тёмный снимок
  посреди страницы бьёт по глазам. Если хочется показать обе темы,
  это отдельная пара снимков, а не замена этим.
- PNG, без масштабирования после съёмки: пересжатый скриншот с текстом
  выглядит грязно.
- Личных данных в кадре быть не должно — ни путей вида
  `C:\Users\<имя>\…` в заголовке окна, ни чужих файлов в «Недавних».
